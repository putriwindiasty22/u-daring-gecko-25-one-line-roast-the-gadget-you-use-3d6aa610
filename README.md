## The roast

> My smartwatch just gave me a badge for standing up — turns out gravity and I have been in a title fight all along.

The gadget roasted is the smartwatch so many of us wear every day: it treats standing up — the lowest bar in human movement — as a championship achievement worthy of a badge.

## How it works

`main.ts` writes a single original roast line (under 200 characters) to `/output/entry.txt`. Run it with Node 22:

```sh
node main.ts
```
